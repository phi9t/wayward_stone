# Rothfuss-Style Rewrite Guide (Reference)

Adapted to be manuscript-agnostic and run-root agnostic.

Known run roots: `gpt53/`, `kimi25/`, `kimi25_blend/`. Future run roots are supported.

## 1) Never explain the point of the scene

Cut interpretation lines:
- “I realized…”
- “This meant…”
- “It was clear…”
- “I understood…”

Replace with:
- a physical reaction that contradicts the words
- a deflection in dialogue
- a habit breaking at the wrong moment

Rule of thumb: if a sentence interprets an emotion, try cutting it first.

## 2) Dialogue is a game of evasion

Preferred rhythm:

`Question → Deflection → Pressure → Small, accidental truth`

Notes:
- Keep lines short.
- Avoid speeches.
- Let characters “win” by not answering.

## 3) Kvothe can be clever without others being stupid

Ensure other characters:
- correct him,
- out-wait him,
- or win an exchange quietly.

If Kvothe dominates every conversation, the scene usually needs rebalancing.

## 4) Humor is defense

Jokes belong under stress. Use humor to:
- mask fear,
- dodge sincerity,
- or undercut a looming truth.

## 5) Character is habit + interruption

Template:

1. Establish a small physical habit (counting, smoothing sleeves, arranging papers, tapping a rhythm).
2. Put pressure on it.
3. Break the habit at the moment of truth.

## 6) Scenes end early

Prefer ending on:
- an unanswered line,
- someone leaving,
- a silence that changes the room.

If a scene feels neatly resolved, stop earlier.

## Rewrite template (copy/paste)

```markdown
[Physical habit]
[Dialogue: question → deflection → pressure]
[Accidental truth leaks]
[Physical interruption / break]
[Exit or silence]
```

## Micro-diagnostic checklist

- Did I explain the emotion instead of showing it?
- Did anyone answer a question too cleanly?
- Does a habit break under pressure?
- Does the scene end on a resonant incompletion?
