# Wayward Stone Rothfuss Style

Use this skill when the user asks to make a passage “more Rothfuss,” tighten dialogue/subtext, or revise scenes to end earlier and land emotional turns without explaining them.

## Run-root context

- This skill is run-root agnostic and should inherit the active `RUN_ROOT` from the current writing workflow.
- Known run roots: `gpt53/`, `kimi25/`, `kimi25_blend/` (plus future run roots with chapter files).

## Default approach

1. Identify the scene’s turn (what must change).
2. Remove explicit interpretation (“I realized…”, “this meant…”).
3. Rebuild dialogue as pressure/deflection with a small accidental truth.
4. Put character in the body (habit), then break it (interruption).
5. End the scene early: unanswered line, exit, or silence.
